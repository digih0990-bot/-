# کلاس‌یار — نمونهٔ اولیهٔ کلاس آنلاین زنده

این پروژه یک وب‌سایت اولیه با رابط فارسی، ورود به اتاق کلاس، دوربین، میکروفون، اشتراک صفحه و چت زنده است. برای تماس واقعی چندنفره از LiveKit استفاده می‌کند.

## برای راه‌اندازی واقعی چه لازم است؟
1. یک سرویس LiveKit بسازید: https://cloud.livekit.io/
2. نشانی سرور، API Key و API Secret را در تنظیمات محیطی سرور قرار دهید. فایل `.env.example` نمونهٔ نام متغیرهاست؛ فایل حاوی کلیدهای واقعی را در اینترنت منتشر نکنید.
3. روی یک میزبان Node.js با HTTPS مستقر کنید و دستور `npm install` و سپس `npm start` را اجرا کنید.
4. برای نقش معلم، متغیر `TEACHER_CODE` را تنظیم کنید و کد را خصوصی نگه دارید.
5. قبل از استفادهٔ مدرسه‌ای، احراز هویت واقعی، فهرست مجاز دانش‌آموزها، سیاست حریم خصوصی و مدیریت دسترسی را اضافه و آزمایش کنید.

## اجرای محلی
- Node.js نسخهٔ 20 یا جدیدتر نصب باشد.
- `npm install`
- متغیرهای محیطی LiveKit را تنظیم کنید.
- `npm start`
- در مرورگر `http://localhost:3000` را باز کنید.

برای آزمایش دوربین و میکروفون روی دستگاه‌های دیگر، سایت باید روی HTTPS میزبانی شود. localhost فقط برای آزمایش همان دستگاه مناسب است.

## نکات مهم
- این یک نمونهٔ اولیه است، نه سرویس مدرسه‌ای آمادهٔ انتشار.
- نقش معلم در نسخهٔ اولیه با کد محرمانه بررسی می‌شود؛ برای استفادهٔ واقعی، ورود امن و کنترل دسترسی قوی‌تر لازم است.
- هیچ ضبطی در این برنامه پیاده‌سازی نشده است. ضبط یا ذخیرهٔ تصویر و صدا را بدون اطلاع و رضایت مناسب فعال نکنید.
- ظرفیت نامحدود نیست؛ ظرفیت واقعی به طرح سرویس، پهنای باند، دستگاه‌ها و تعداد ویدئوهای هم‌زمان بستگی دارد.
- در کلاس کودکان، بهتر است معلم بتواند دوربین/میکروفون را مدیریت کند، دانش‌آموزها بتوانند خودشان خاموش کنند و اطلاعات ورود خصوصی بماند.
